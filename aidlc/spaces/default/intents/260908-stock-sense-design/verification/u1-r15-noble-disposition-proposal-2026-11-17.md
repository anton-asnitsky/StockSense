## Component removal assessment

- `libc6` and its loader are necessary to the glibc-based .NET runtime. Removing them breaks the approved runtime model. The patched package addresses the six available fixes.
- `libssl.so.3`, `libcrypto.so.3` and the .NET native OpenSSL shim exist in the image. .NET imports OpenSSL APIs for cryptography. Whole-library removal needs complete .NET/Kiota feature analysis and regression evidence; the current evidence does not support it. The `openssl` executable is already absent. Its Chisel-selected configuration and source attribution still generate an SBOM package identity, which must be retained.
- ICU `uc`, `i18n` and data libraries support the required globalization behavior. Removing ICU or switching to invariant mode conflicts with the verified French and Jerusalem behavior. The manifest also contains `libicuio`, `libicutu` and `libicutest`. Narrowing these optional slices could reduce surface after dependency verification, but it alone would not resolve an installed source-package match.
- The `genrb` executable and a `libcrypt`-named shared object are absent from the full manifest. ICU's affected `SRBRoot::addTag` source is in the genrb tool build. These observations support further not-affected review. Static copies, native symbol identity and whole-process reachability remain unverified.
