# R-15 isolated Azure Linux Kiota screening, 2026-11-17

**Reject this runtime candidate.** Microsoft’s OSV advisories identify eight distinct glibc CVEs and four distinct OpenSSL CVEs at the versions in the assembled image. Both raw Grype scans reported zero matches. Of the 20 prior Ubuntu rows, 16 map to vendor-affected source releases, one maps to a fixed ICU release, and three remain unresolved (two distinct CVEs). The review covers the prior findings and does not exhaust all vendor advisories.

## Positive control

[Run 44121530430](https://github.com/anton-asnitsky/StockSense/actions/runs/44121530430) imported the identical authenticated archive with Grype’s native database command. It changed only the two ICU component identities in a separate diagnostic SBOM from release 2 to release 1. Offline Grype returned CVE-2025-5222 twice for icu 72.1.0.3-1.azl3, once per component identity. Sample sensitivity and provider coverage were demonstrated, while the production-image matches missed the vendor-affected releases above.
