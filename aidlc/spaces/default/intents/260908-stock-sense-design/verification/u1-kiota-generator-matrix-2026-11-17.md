## Before and after the generator upgrade

The Windows generation suites ran 14 tests each with zero skips at both 1.35.0 baselines, story `8e44978078965cd0350579d90f223853211a6606` and combined `0d9461a607e2d83becd55ac7bbcd97124cc6fb1b`. After the 1.38.0 upgrade, each source tree again passed all 14. On each tree, two independent empty output directories reproduced one TypeScript REST output, two Modelina outputs and 104 Kiota outputs. The .NET tree contains 103 C# files and one generator lock file. The C# files matched byte-for-byte across versions. The only changed generated bytes were the version string in `kiota-lock.json`. Story and combined C18 inputs differ and each retained its own output profile.

The .NET 10 compile and smoke test used Microsoft.Kiota.Bundle 2.1.6. Both generated clients issued a synthetic session GET through an in-memory HTTP handler, decoded a subject ID and empty retailer list, and serialized the two expected version properties of a manual-review request. This exercises request construction, response decoding, and payload encoding. No provider service received a request.
